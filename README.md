# FreedomLLM

FreedomLLM is a general-purpose LLM inference engine that helps AI engineers deploy and run AI models easily.

## Installation

### Install the Project

```bash
python pip install --editable .
```

### Install Test Dependencies

```bash
python pip install --group test
```

## Testing

### Run Tests

```bash
python -m pytest
```
